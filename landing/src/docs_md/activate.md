# Device and Account Activation

The Activation Page is used to activate the UTIM CLI on a local machine using a device flow or web authorization link.

## Features
- **Device Pairing:** Users can enter the pairing code generated by the CLI in their terminal to securely link their web account to the local agent.
- **Token Issue:** Once activated, the web platform issues a secure authentication token to the CLI for API requests and quota usage.
- **Management:** Users can manage active devices in their Profile page.

For troubleshooting activation issues, ensure you are logged in with the correct account before entering the pairing code.
