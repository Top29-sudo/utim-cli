# Authentication (Login & Signup)

The Authentication pages (Login and Signup) allow users to access the UTIM platform.

## Methods
- **Google OAuth:** Fast, secure single-sign-on using your Google account.
- **GitHub OAuth:** Fast, secure single-sign-on using your GitHub account (ideal for developers).
- **Email/Password:** Traditional login using an email and password.

## Password Reset
Users can reset their password from the login screen if they forget it. A secure reset link is sent to their registered email.

To manage sessions, users can visit their Profile page after authenticating.
