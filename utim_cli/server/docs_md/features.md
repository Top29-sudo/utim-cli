# UTIM CLI Features

UTIM is an autonomous AI software engineer for local environments.

## Core Capabilities
- **Autonomous Planning**: Rigorous think-act-observe cycle. UTIM creates checklist plans, writes code, executes builds/tests, and self-corrects until completion.
- **System Control (Root Access)**: Natively runs secure shell commands locally, fully sandboxed.
- **Browser Automation (Pixel Perfect)**: Launches Playwright to visually inspect UI changes, capture screenshots, and fix layout/CSS bugs autonomously.
- **Domain Adaptation (Custom Skills)**: Supports custom markdown guidelines (e.g. `SKILL.md`) in its workspace config to learn APIs, coding standards, and proprietary frameworks.
- **Pair Programming (Human-in-the-loop)**: Allows the user to interrupt, provide feedback mid-task, and guide files.
- **Model Context Protocol (MCP)**: Standardized integration with database servers, Figma, Slack, or GitHub.
